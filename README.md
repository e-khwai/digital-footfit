# Digital Footfit

> ก็แค่รูป Screenshot เองครับ จะจริงจังอะไรขนาดนั้น? ไม่พอใจโปรเจกต์นี้ก็ Report เอานะครับ มีระบบ Issue อยู่แล้ว ไม่พอใจก็เปิด Issue สิ

ยินดีต้อนรับสู่ **Digital Footfit** คลังเก็บภาพโพสต์จากดราม่าบนอินเทอร์เน็ต เผื่อวันหนึ่งเราอยากกลับมาดูว่า ตอนนั้นใคร *ให้เหตุผลว่าอะไร* ไว้บ้าง

## มีอะไรอยู่ในนี้

โปรเจคเรียงตาม **ดราม่า → แพลตฟอร์ม → ภาพ** แบบนี้นะ

```text
dramas/
└── 2026/
    └── drama_name/
        ├── README.md
        ├── x/
        │   ├── account_a_01.png
        │   └── account_a_02.png
        ├── facebook/
        │   └── account_b_01.png
        └── threads/
            └── account_c_01.png
```

ภาพด้านบนเป็นตัวอย่างชื่อไฟล์ ไม่ใช่ไฟล์ภาพจริง

## อยากเพิ่มรูป?

อ่านขั้นตอนเต็ม ๆ ที่ [CONTRIBUTING.md](CONTRIBUTING.md)

## Rule

- เก็บเฉพาะโพสต์สาธารณะที่เข้าถึงได้
- ไม่ลง DM, ข้อมูลส่วนตัว, เบอร์โทร, ที่อยู่ หรือข้อมูลที่ชวนให้ตามตัวคน
- ปิดข้อมูลระบุตัวบุคคลที่ไม่จำเป็นในภาพ
- ไม่รับภาพที่ตัดต่อหรือครอปจนทำให้ความหมายเปลี่ยน
- ห้ามใช้ Repo นี้ไปถล่ม Report, Mention หรือรุมด่าใคร
- ภาพที่มีปัญหาขอให้แจ้งแก้ไข/นำออกได้ ดู [docs/content-policy.md](docs/content-policy.md)

## ไม่พอใจ?

เปิด Issue เพื่อแจ้งข้อมูลผิด บริบทหาย ภาพซ้ำ หรือขอให้ตรวจสอบการนำภาพออกได้เลยครับ

## Disclaimer

ภาพในคลังเป็นบันทึกสิ่งที่ปรากฏ ณ เวลาจับภาพ ไม่ใช่การรับรองความถูกต้องของทุกข้อความ และไม่ใช่การกล่าวหาว่าบุคคลใดมีความผิด ผู้ดูแลอาจปฏิเสธ แก้ไข หรือถอดรายการที่ขาดบริบท ละเมิดสิทธิ หรือเสี่ยงทำให้เกิดการคุกคาม
