# Content Policy

เป้าหมายของ repo นี้คือเก็บหลักฐานประกอบการศึกษาบทสนทนาสาธารณะ ไม่ใช่ทำฐานข้อมูลบุคคลที่ใช้ตามไปคุกคาม

## หลักการ

1. **ไม่บิดความหมาย:** ไม่ครอปหรือเลือกภาพจนผู้ชมเข้าใจข้อโต้แย้งผิด
2. **ข้อมูลส่วนตัวให้น้อยที่สุด:** ไม่เผยแพร่ข้อมูลติดต่อหรือรายละเอียดส่วนบุคคล
3. **ไม่ชี้เป้า:** ห้ามทำรายชื่อเพื่อให้ผู้อื่นไปตามด่า หรือยุให้เกิดการรุมรายงานบัญชี


## ขอแก้ไข / นำออก

เปิด Issue ระบุ path ของไฟล์ ปัญหา และหลักฐานที่จำเป็น โดยไม่ส่งข้อมูลส่วนตัวเพิ่มเติม ผู้ดูแลอาจซ่อนหรือลบไฟล์ระหว่างการตรวจสอบ ทั้งนี้การลบไฟล์จาก Commit ล่าสุดไม่ได้ลบสำเนาที่เคยถูก Fork หรืออยู่ในประวัติ Git
